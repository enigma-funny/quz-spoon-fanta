Question 601 :
The higher the resolution of a monitor, the _________

  1. larger the pixels.
  2. closer together the pixels.
  3. further apart the pixels.
  4. less clear the screen is.
   closer together the pixels.

Question 617 :
Which of the following is true?

  1. Byte is a single digit in a binary number
  2. Bit represents a grouping of digital numbers
  3. Eight-digit binary number is called a byte
  4. Eight-digit binary number is called a bit
   Eight-digit binary number is called a byte

Question 618 :
Binary coded decimal (BCD) numbers express each decimal digit as a

  1. bit
  2. byte
  3. nibble
  4. binary digit
   nibble

Question 619 :

  1. Internet
