Question 1591 :
The type of rainfall shown in figure is:

  1. orographic
  2. convectional
  3. cyclonic
  4. relief
   convectional

Question 1592 :
Which region in India is known as the 'Rice Bowl of India'?

  1. Indo-Gangetic Plain
  2. Krishna-Godavari Delta region
  3. North-East region
  4. Kerala and Tamil Nadu
   Krishna-Godavari Delta region

Question 1593 :
The Mopplah are to be found in

  1. Manipur
  2. Assam
  3. Kerala
  4. Andhra Pradesh
   Kerala

Question 1594 :
Which of the following clties/towns does not lie on the banks of the Ganga?

  1. Kanpur
  2. Fatehpur
  3. Ghazipur
  4. Farrukhabad
   Fatehpur

Question 1595 :
Which of the following States of India do not lie entirely in the Tropical Zone of the Earth?

  1. Kerala and Tamil Nadu
  2. Gujarat
  3. Maharashtra and Andhra Pradesh
   Gujarat

Question 1596 :
The Laccadives are an example of

  1. Islands resulting from submarine earthquakes
  2. Volcanic Islands
  3. Coral Islands
  4. None of the above
   Coral Islands

Question 1597 :
Wild asses are found in

  1. Parkal, Warangal (Andhra Pradesh)
  2. Rann of Kutch, Gujarat
  3. Manas, Barpeta (Assam)
  4. Chandraprabha, Varanasi
   Rann of Kutch, Gujarat

Question 1598 :
The paleomagnetic results obtained from India indicate that in the past, the Indian landmass has moved

  1. northward
  2. southward
  3. eastward
  4. westward
   northward

Question 1599 :
Which among the following pairs of places have most marked difference in total rainfall per annum even though located approximately along the same latitude?

  1. Bengaluru and Chennai
  2. Mumbai and Visakhapatnam
  3. Ajmer and Shillong
  4. Nagpur and Kolkata
   Ajmer and Shillong

Question 1600 :
Where was the first cotton mill set up in India?

  1. Mumbai
  2. Coimbatore
  3. Surat
  4. Kolkata
   Kolkata

Question 1601 :
In general it la observed that the rate of population growth has been ________ in the densely populated areas compared to sparsely populated areas.

  1. Low
  2. High
  3. Negligible
  4. Almost the same
   Low

Question 1602 :
The Alamatti is on the river

  1. Godavari
  2. Cauvery
  3. Krishna
  4. Mahanadi
   Krishna

Question 1603 :
Sivasamudram waterfalls is on the river

  1. Krishna
  2. Godavari
  3. Mahanadi
  4. Cauvery
   Cauvery

Question 1604 :
Economically exploitable lignite occurs in

  1. Andhra Pradesh
  2. Tamil Nadu
  3. Karnataka
  4. Kerala
   Tamil Nadu

Question 1605 :
Consider the following animals of India: 1. Crocodile 2. Elephant - Which of these is/are endangered species?

  1. Only 1
  2. Only 2
  3. Both 1 and 2
  4. Neither 1 nor 2
   Both 1 and 2

Question 1606 :
Which of the following hill stations is not located in Himachal Pradesh?

  1. Kulu
  2. Manali
  3. Shimla
  4. Ranikhet
   Ranikhet

Question 1607 :
The bridge of sand and rock in the Palk Strait between India and Sri Lanka is

  1. Palk Isthmus
  2. Sri Lanka Bridge
  3. Adam's Bridge
  4. Pamban Bridge
   Adam's Bridge

Question 1608 :
The first range of Himalayas to the North of Ganga Plains is the

  1. Satpura Mountains
  2. Shiwaliks
  3. Garo Hills
  4. Khasi Hills
   Shiwaliks

Question 1609 :
The Satpura Thermal Power Station is in

  1. Uttar Pradesh
  2. Jammu and Kashmir
  3. Madhya Pradesh
  4. Maharashtra
   Madhya Pradesh

Question 1610 :
In which one of the following cities can one never have the sunshine directly overhead at noon?

  1. Bengaluru
  2. Mumbai
  3. Visakhapatnam
  4. Delhi
   Delhi

Question 1611 :
The National Metallurgical Laboratory of India is at

  1. Jamshedpur
  2. Dhanbad
  3. Roorkee
  4. Ranchi
   Jamshedpur

Question 1612 :
The first marine sanctuary in India, having within its bounds coral reefs, mollusca, dolphins, tortoises and various kinds of sea birds, has been established in

  1. Sundarbans
  2. Chilka Lake
  3. Gulf of Kachchh
  4. Lakshadweep
   Chilka Lake

Question 1613 :
Which of the following regions has almost all prevalent types of natural vegetation in India?

  1. The Coastal Plains
  2. The Deccan Plateau
  3. The Himalayas
  4. The Ganga Plain
   The Himalayas

Question 1614 :
Which of the following is a tropical monsoon crop?

  1. Jowar
  2. Chillies
  3. Rice
  4. Ragi
   Rice

Question 1615 :
Which of the weathering agents is almost peculiar to the Indian Himalayas?

  1. Wind
  2. Glaciers
  3. Snowfall
  4. Running water
   Glaciers

Question 1616 :
In India, diamonds are found at

  1. Panna (MP)
  2. Golkonda (AP)
  3. Khetri (Rajasthan)
  4. None of these
   Panna (MP)

Question 1617 :
Which multipurpose project was taken up first of all after independence?

  1. Bhakra Nangal Project
  2. Damodar Valley Project
  3. Kosi Project
  4. None of these
   Damodar Valley Project

Question 1618 :
The Damodar-Tribeni Canal which serves as an irrigationcum-navigation canal is _______ long.

  1. 137km
  2. 147km
  3. 157km
  4. 167km
   137km

Question 1619 :
The monsoon has well-developed cycle in: [CDS 1992]

  1. South and South East Asia
  2. North Australia
  3. East United States
  4. Africa
   South and South East Asia

Question 1620 :
Konkan is a region of which one of the following States?

  1. Karnataka
  2. Maharashtra
  3. West Bengal
  4. Kerala
