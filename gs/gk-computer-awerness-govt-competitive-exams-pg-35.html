Question 1021 :
What is the term for unsolicited e-mail?

  1. News group
  2. Use net
  3. Backbone
  4. Spam
   Spam

Question 1022 :
The process of a computer receiving information from a server on the Internet is known as

  1. pulling
  2. downloading
  3. pushing
  4. uploading
   downloading

Question 1023 :
Which of the following input device is used in Banks to read magnetised characters on a Cheque?

  1. OCR
  2. MICR
  3. Bar Code reader
  4. Magnetic Stripe reader
   MICR

Question 1024 :
Which device can understand the difference between data and program?

  1. Input device
  2. Output device
  3. Memory
  4. Microprocessor
   Microprocessor

Question 1025 :
Which of the following are objects in an access database?

  1. table, form
  2. queries, reports
  3. macros, modules
  4. All the above
   All the above

Question 1026 :
The quickest and easiest way in Word, to locate a particular word or phrase in a document is to use the ....... command

  1. Replace
  2. Find
  3. Lookup
  4. Search
   Find

Question 1027 :
To save an existing file with a new name or a new location, you should use _________command.

  1. save
  2. save and replace
  3. new file
  4. save as
   save as

Question 1028 :
To change hardware components into more powerful or rectified version is called

  1. expansion
  2. plug and play
  3. upgrading
  4. upsizing
   upgrading

Question 1029 :
The speedometer of a car represents

  1. digital computer
  2. hybrid computer
  3. analog computer
  4. micro computer
   analog computer

Question 1030 :
To maximise a window means

  1. fill it to capacity
  2. expand it to fit the desktop
  3. put only like files inside
  4. drag it to the recycle bin
   expand it to fit the desktop

Question 1031 :
One advantage of dial-up-internet access is ___

  1. It utilises broadband technology
  2. It utilizes existing telephone service
  3. It uses a router for security
  4. Modem speeds are very fast
   It utilizes existing telephone service

Question 1032 :
When installing ............., the user must copy and usually decompress program files from a CDROM or other medium to the hard disk

  1. programming software
  2. system hardware
  3. applications hardware
  4. applications software
   programming software

Question 1033 :
What is the intersection of a column and a row called on an Excel worksheet?

  1. Column
  2. Value
  3. Address
  4. Cell
   Cell

Question 1034 :
In EDSAC, an addition operation was completed in _____ micro seconds

  1. 4000
  2. 3000
  3. 2000
  4. 1500
   1500

Question 1035 :
When you are working on a document on PC, where is the Document temporarily stored?

  1. RAM
  2. ROM
  3. The CPU
  4. Flash memory
   RAM

Question 1036 :
The purpose of the primary key in a database is to :

  1. unlock the database
  2. provide a map of the data
  3. uniquely identify a record
  4. establish constraints on database operations
   provide a map of the data

Question 1037 :
How are data organised in a spreadsheet?

  1. Lines and spaces
  2. Layers and planes
  3. Height and width
  4. Rows and columns
   Height and width

Question 1038 :
A _____ contains specific rules and words that express the logical steps of an algorithm.

  1. Syntax
  2. Programming structure
  3. Programming language
  4. Logic chart
   Programming language

Question 1039 :
What is output?

  1. What the processor takes from the user.
  2. What the user gives to the processor.
  3. What the processor rejects.
  4. What the processor gives to the user.
   What the processor gives to the user.

Question 1040 :
Which of the following is part of the system unit?

  1. Monitor
  2. CPU
  3. CD?ROM
  4. Floppy disk
   CPU

Question 1041 :
............ are lists of commands that appear on the screen

  1. GUIs
  2. Icons
  3. Menus
  4. Windows
   Menus

Question 1042 :
Storage that retains its data after the power is tuned off is referred to as

  1. volatile storage
  2. non-volatile storage
  3. sequential storage
  4. direct storage
   non-volatile storage

Question 1043 :
A disadvantage of the laser printer is :

  1. It is quieter than an impact printer
  2. It is very slow
  3. The output is of a lower quality
  4. None of these
   None of these

Question 1044 :
A series of to?be?viewed specially designed documents, which are all linked on Internet, is called:

  1. World Wide Web
  2. Web Server
  3. Search Engine
  4. Both 2) and 3)
   World Wide Web

Question 1045 :
IC is made up of _________

  1. microprocessor
  2. vacuum tube
  3. transistor
  4. None of the Above

Question 1046 :
Blueprints are usually created using ____________software.

  1. CGI
  2. Paint
  3. Draw
  4. CAD
   CAD

Question 1047 :
___________programs perform day to day tasks related to the maintenance of the computer system

  1. Operating system
  2. System Utilities
  3. Language translators
  4. Application software
  System Utilities

Question 1048 :
The computer or system peripherals that receives data from processing unit are called ___________

  1. Input Devices
  2. Output Devices
  3. Both (A) and (B)
  4. None of the Above
