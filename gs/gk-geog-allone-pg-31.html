Question 901 :
Mediterranean climate prevails in

  1. Central Chile
  2. Northern Chile
  3. Peru
  4. Argentina
   Central Chile

Question 902 :
You are asked to import Ostrich, Platypus and Kaola Bear. To which country will you opt to go, to get all the three?

  1. Australia
  2. Japan
  3. Canada
  4. New Zealand
   Australia

Question 903 :
Wular lake of Kashmir is a : [IAS 2003]

  1. Ox- bow lake
  2. Lake formed by blocking of ice
  3. Lake formed by terminal morainic dam
  4. Lake formed by deposition of silt
   Lake formed by terminal morainic dam

Question 904 :
Among the following areas, the widest continental shelf of India is found: [IAS 1991]

  1. around the Gulf of Cambay
  2. around the Konkan coast
  3. off the Krishna and Godavari deltas
  4. around the Palk strait
   off the Krishna and Godavari deltas

Question 905 :
Which of the following gives the correct descending order by length of the rivers of India?

  1. Brahmaputra, Ganga, Godavari, Kosi
  2. Ganga, Brahmaputra, Krishna, Godavari
  3. Ganga, Godavari, Krishna, Yamuna
  4. Ganga, Yamuna, Godavari, Mahanadi
   Ganga, Godavari, Krishna, Yamuna

Question 906 :
The river Cauvery originates from which of the following states? [Bank PO 1994]

  1. Andhra Pradesh
  2. Tamil Nadu
  3. Karnataka
  4. Madhya Pradesh
   Karnataka

Question 907 :
Which one of the following barrages supplies water to the Indira Gandhi Canal? [CDS 2002]

  1. Bhakra
  2. Harika
  3. Narora
  4. Pandoh
   Harika

Question 908 :
The Trans-Siberian railway links

  1. The Baltic coast with the North Sea
  2. Leningrad with Oldiotsk
  3. Buanos Aires with Valparaiso
  4. Leningrad with Vladivostok
   Leningrad with Vladivostok

Question 909 :
The Tibetan river 'Tsangpo' enters India through the State of: [NDA 2004]

  1. Arunachal Pradesh
  2. Assam
  3. Manipur
  4. Nagaland
   Arunachal Pradesh

Question 910 :
By what name is the Ganga known in Bangladesh?

  1. Padma
  2. Bhagirathi
  3. Rupnarayan
  4. Nubra
   Padma

Question 911 :
The strait that separates Tasmania from the mainland of Australia is

  1. Cook Strait
  2. Bass Strait
  3. Torres Strait
  4. Palk Strait
   Bass Strait

Question 912 :
In the realm of coal production in the world, India ranks: [NDA 2002]

  1. first
  2. second
  3. third
  4. fourth
   fourth

Question 913 :
Which one of the following cities is not located on the bank of river Ganga? [BPSC 2011]

  1. Fatehpur
  2. Bhagalpur
  3. Uttarkashi
  4. Kanpur
   Uttarkashi

Question 914 :
Which of the following natural regions has specialised in cultivation of fruit trees?

  1. Mediterranean region
  2. Warm Mid-latitude East Margin region
  3. Tropical East Margin region
  4. Mid-latitude Grassland region
   Mediterranean region

Question 915 :
Among the following rivers, which one is the longest? [Asstt Comm 2008]

  1. Godavari
  2. Krishna
  3. Mahanadi
  4. Narmada
   Godavari

Question 916 :
Rubber is the coagulated Juice or latex or an equatorial tree called

  1. Ebony
  2. Mahogany
  3. Cinchona
  4. Hevea
   Hevea

Question 917 :
Consider the following seaports: 1. Chenna 2. Machilipattina 3. Nagapattina 4. Tuticorin - The correct sequence of these ports as one moves from north to south is : [CDS 2000]

  1. 1, 2, 3, 4
  2. 2, 1, 3, 4
  3. 1, 3, 2, 4
  4. 2, 1, 4, 3
   2, 1, 3, 4

Question 918 :
In which of the following states, Teesta Urja hydro-power project is proposed to be set up?

  1. Sikkim
  2. Andhra Pradesh
  3. West Bengal
  4. Arunachal Pradesh
   Sikkim

Question 919 :
Which of the following rivers flows through Maharashtra and Gujarat ? [CDS 1993]

  1. Sabarmati
  2. Godavari
  3. Mahi
  4. Tapti
   Tapti

Question 920 :
Which soil is sticky when wet and develops cracks when dry

  1. alluvial soil
  2. black soil
  3. red soil
  4. late rite soil
   black soil

Question 921 :
Which State of India has the largest reserves of monazite, with a high thorium content? [CPO SI 2002]

  1. Kerala
  2. Karnataka
  3. Gujarat
  4. Maharashtra
   Kerala

Question 922 :
Tropical deserts are rich in _____ resources.

  1. mineral
  2. agricultural
  3. soil
  4. animal
   mineral

Question 923 :
Geothermal energy may serve as an important source of energy in

  1. The Konkan Coast
  2. Ladakh District
  3. Aravalli Hills
  4. Narmada Valley
   Ladakh District

Question 924 :
In Jaitapur, which one of the following power plants is being set up? [Haryana Gr Bank PO 2011]

  1. Coal based
  2. Hydro-electric
  3. Gas based
  4. Nuclear based
   Coal based

Question 925 :
Consider the following cities: 1. Bhatinda 2. Jamnagar 3. Mangalore . - Which of the above has/have oil refineries? [Asstt Comm 2008]

  1. 1 and 2
  2. 3 only
  3. 2 and 3
  4. 1, 2 and 3
   2 and 3

Question 926 :
Which of the following substances are found in the beach sands of many parts of Kerala? 1. Ilmenite 2. Zircon 3. Silimanite 4. Tungsten. - Select the correct answer using the code given below: [IAS 2006]

  1. 1, 2, 3 and 4
  2. 1, 2 and 3
  3. 3 and 4 only
  4. 1 and 2 only
   1, 2 and 3

Question 927 :
Which of the following was India's first mobile offshore drillng platform?

  1. Sagar Kanya
  2. Sagar Mata
  3. Sagar Samrat
  4. None of the above
   None of the above

Question 928 :
Ankaleshwar and Navagaon are two oil fields in :

  1. Gujarat
  2. Bihar
  3. West Bengal
  4. Assam
   Gujarat

Question 929 :
The Trans-Andean railway connects

  1. Mexico City with Santiago
  2. Panama City with Santiago
  3. Buenos Aires with Valparaiso
  4. Rio de Janerio with Bogota
