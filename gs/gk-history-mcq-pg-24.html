Question 691 :
Egyptians were highly skilled in the art of

  1. Sacred script
  2. Religious script
  3. Sumerian script
  4. Iraqi script
   Sumerian script

Question 692 :
The chief feature of the temples constructed by the Cholas was their—

  1. Gopurams or gateways
  2. Vimanas or Towers
  3. Assembly-halls for the devotees

Question 698 :
Which one of the following pairs is correctly matched? Dynasties Rulers

  1. It meant dereliction of duty

Question 709 :
