Question 991 :
Which of the following is the largest unit of storage?

  1. GB
  2. KB
  3. MB
  4. TB
   GB

Question 992 :
The software component of an expert system that draws conclusions is the ___________.

  1. user interface
  2. database
  3. inference engine
  4. I/O controller
   inference engine

  2. title

What is an email attachment?

Question 1006 :
A nibble is equal to _______

  1. 4 bits
  2. 8 bits
  3. 16 bits
  4. 32 bits

Question 1007 :
Printer resolution is usually measured in ________

  1. Characters Per Minute (CPM)
  2. Pixels Per Inch (PPI)
  3. Pages Per Minute (PPM)
  4. Dots Per Inch (DPI)
   Dots Per Inch (DPI)

Question 1008 :
